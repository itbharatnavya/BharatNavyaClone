# Legacy UI archive

Everything in this directory is non-authoritative and excluded from current product work.

- `vite-design-reference/` is the former root `Design/` prototype. It is kept intact for historical comparison only.
- `root-vite-artifacts/` contains ignored local build/dependency artifacts that previously sat at the repository root. These are not source files and are not expected in a fresh clone.

The only official frontend is `/frontend`. Do not run, import, patch, or copy contracts from this archive unless the user explicitly asks for historical analysis. Archived fixtures are not production data or API contracts.
