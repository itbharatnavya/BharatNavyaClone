# Direction 04 — Smart Platform Navigator

## The thinking

This direction explores the clearest useful role for AI in Bharat Navya: helping people express what they need and understand why particular companies or jobs appear. The interface begins with natural language but immediately translates it into conventional, inspectable search controls.

The central question is: **How can Bharat Navya make complex discovery easier without asking users to trust a black box?** The answer is editable filters, plain-language explanations, and user-reviewed drafting inside otherwise familiar Directory and Recruitment pages.

## Visual direction

- Graphite, Electric Blue, Sea Green, Soft Apricot, Frost, and white.
- Bricolage Grotesque-like display type with highly legible Atkinson-like body copy.
- Crisp bordered cards, medium corner radius, restrained shadows, and clear control states.
- More interactive and product-led than the other options, without dashboard or command-centre styling.
- Search and filter controls form the main visual signature.

## Important features

- Large universal natural-language search.
- Editable intent, category, location, and workplace filters.
- Equal Directory and Recruitment gateways.
- Familiar company and job preview cards.
- **Why this result** explanations citing visible match criteria.
- Conventional job detail with employer context and workplace evidence.
- Optional application drafting followed by explicit review and user submission.
- Related roles and practical guides.
- Freshness and public-update signals.

## AI role

AI translates intent into editable filters, explains results using visible evidence, and can help draft application text. Every consequential action remains under user control:

1. AI prepares a draft.
2. The user reviews and edits it.
3. The user chooses whether to submit.

There is no autonomous ranking, auto-application, auto-contact, hidden score, or generic chatbot panel.

## Advertising approach

Sponsored cards use the Soft Apricot treatment and a clear label. They sit outside result explanations and application actions and never receive verified styling.

## Why choose this direction

- Demonstrates a useful, credible AI differentiator.
- Reduces search friction for users who do not know platform categories.
- Maintains transparency through editable filters and factual explanations.
- Can be introduced progressively without redesigning every underlying page.

## Risks to manage

- The AI layer must not become more prominent than Directory and Recruitment.
- Search interpretation errors need easy correction and visible uncertainty.
- Drafting assistance requires privacy controls and explicit user approval.
- The interface should remain simple when AI is unavailable.
