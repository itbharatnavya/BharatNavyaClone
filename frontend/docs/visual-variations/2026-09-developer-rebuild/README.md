# Bharat Navya — restrained visual variations

This package contains five concept-only refinements of the active Bharat Navya frontend. They retain its calm, spacious public journey while varying type, color temperature, hero treatment, section framing, and a single useful interaction.

Each direction contains four review screens:

- `home-desktop.png`
- `companies-desktop.png`
- `jobs-desktop.png`
- `home-mobile.png`

The images do not represent implemented product behavior. They use fictional records and preserve the public Home → Companies → Jobs scope. No files in `frontend/app/` or the frozen `Design/` reference are changed.

## Comparison

| Direction | Visual character | Subtle interaction | Strongest use |
| --- | --- | --- | --- |
| 01 Quiet Confidence | familiar, clear blue and white | proof-card selection | safest refinement |
| 02 Warm Ledger | softer ivory and ink | guide/category tabs | more editorial warmth |
| 03 Clear Horizon | cool mist blue and crisp lines | search suggestion chips | search-led discovery |
| 04 Local Signal | sage, navy, and photo-led proof | featured-record switcher | company trust and evidence |
| 05 Open Desk | airy neutral canvas and cobalt | compact section accordion | most minimal landing page |

## Review criteria

- Search is the single dominant landing-page action, centered and unobstructed.
- Companies and Jobs remain equal product pillars.
- Layouts leave visible breathing room; imagery supports rather than competes with action.
- Sponsored content, if visible, is clearly separate from organic records.
