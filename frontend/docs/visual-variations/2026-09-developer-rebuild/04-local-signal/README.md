# 04 — Local Signal

**Thesis:** Trust comes from work, place, and recency: one spacious image-backed record gives the platform a human local signal without turning it into a feed.

**Palette / type:** Navy `#16305C`, sage `#5E8A77`, soft gold `#C98A38`, stone `#F4F3EF`, white. Neutral sans with compact utility labels.

**Signature:** A three-item featured-record switcher changes the company or role evidence panel.

**Tradeoff:** Photography must remain relevant evidence, not decoration.
