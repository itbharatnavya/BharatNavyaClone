# 02 — Warm Ledger

**Thesis:** Keep the platform professional while introducing quiet editorial warmth through ivory surfaces, fine rules, and a restrained serif only for major statements.

**Palette / type:** Ink `#263038`, petrol `#245C68`, clay `#B86746`, ivory `#FBF8F1`, white. Serif display with a clean sans interface.

**Signature:** A small guide/category tab set changes the supporting recommendation beneath the search.

**Tradeoff:** The editorial character needs discipline so it never becomes a media site.
