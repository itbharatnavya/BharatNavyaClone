# 03 — Clear Horizon

**Thesis:** A cool, clear, search-first direction with more open sky-blue space and highly legible information architecture.

**Palette / type:** Graphite `#1D2936`, cobalt `#2764D8`, teal `#167A70`, mist `#EDF4FA`, white. Humanist sans throughout.

**Signature:** Editable intent chips appear below search and remain conventional filters.

**Tradeoff:** It deliberately stays closer to established product conventions.
