# BharatConnect Ecosystem Experiment

This folder is the source of truth for the exploratory all-in-one BharatConnect marketplace, now integrated as the additive **Explore** layer of the prototype. Phase 1 startup/business finding remains a focused, intact journey under **Discover**.

## Deliverables

- [Design system](./DESIGN_SYSTEM.md) — visual language, tokens, component specifications, accessibility, and responsive rules.
- [Building guide](./BUILD_GUIDE.md) — integration architecture, data contracts, exact screen composition, interactions, and acceptance criteria.
- [Token file](./tokens.css) — scoped three-layer CSS tokens for the Explore layer.

## Direction in one sentence

One verified business identity connects a founder to providers, talent, finance referrals, products, and business updates through a single evidence-led marketplace.

## Guardrail

Use this layer to extend—not replace—the existing prototype. Keep Phase 1 fixtures and persisted shortlist/provider state unchanged; Explore owns its own fixtures, scoped styles, and `bharatconnect:ecosystem-lab:` storage namespace. `/ecosystem-lab` remains a direct-entry alias for review.
