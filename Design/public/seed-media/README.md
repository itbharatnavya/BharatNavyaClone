# Prototype seeded media

These files support the fictional Bharat Navya design prototype. They are stored locally so demos do not depend on runtime hotlinks. They are not cleared for production publication.

## Sources

- Company-mark SVGs: the open Logoipsum sample library (`srmullen/svelte-logoipsum` on GitHub).
- Workplace, team, work-sample, portrait, and advertising-demo photography: Unsplash image CDN assets selected for this prototype.

The interface describes these as illustrative prototype media. Fictional company, recruiter, candidate, and advertiser names do not identify the people or organizations shown. A production media migration must replace every asset with licensed, consented material and retain per-asset creator, source URL, license, alt text, and approval metadata.

## Coverage rules

- `logos/`: company and advertiser identity marks.
- `company/`: workplace and careers evidence.
- `people/`: recruiter and candidate portraits.
- `work/`: work samples, events, and updates.
- `ads/`: third-party advertising format demonstrations.

`RightComply Services` and selected people/records intentionally omit media to keep fallback states testable.
